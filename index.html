QUICKSTART GUIDE

TUTORIALS

Direct step-by-step guides for installing, configuring, and removing Ratheuse.

Install

Download archive, extract files, and run the administrator setup.

1
Download Archive Download ratheuse.zip using the release button below.
2
Extract Files Right-click ratheuse.zip and select Extract All to your chosen folder.
3
Run As Administrator Open the extracted folder, right-click ratheuse-setup.exe, and click Run as administrator.
4
Complete Wizard Follow the installer prompts, click Install, and launch Ratheuse when finished.

Setup

Grant sensor permissions, select hardware devices, and configure hotkeys.

1
Launch Application Open Ratheuse from the desktop shortcut or Windows Start menu.
2
Authorize Sensors Click Yes on the UAC prompt to allow hardware sensor monitoring.
3
Select Hardware Open Settings > Hardware and check your active CPU, GPU, and RAM.
4
Set Refresh Rate Set your polling interval in Settings (500ms for gaming, 1000ms standard).
5
Toggle Overlay HUD Press Ctrl+Shift+R to toggle the real-time hardware overlay on screen.

Uninstall

Windows Add or remove programs removal and PC restart.

1
Press Windows, then search Add or remove programs.
2
Find Ratheuse, click it, then click Uninstall.
3
Restart your PC.
