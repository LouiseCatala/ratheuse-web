## Project overview

Ratheuse introduces a PC hardware-monitoring project through an interactive character reveal, a focused CPU / GPU / RAM overview, and installation guidance. This repository contains the website that presents that experience.

| At a glance | What it means |
| --- | --- |
| **Explore** | Switch between spotlight and full-reveal modes |
| **Understand** | Read the advertised CPU, GPU, and RAM monitoring scope |
| **Get started** | Follow the install, configure, and uninstall guides |

## A clearer first impression

The warm orange palette and interactive character give the site a recognizable identity. Its practical side is the tutorial section: visitors can move from discovering the project to understanding the setup steps. Download availability and the desktop monitor itself are separate from this website preview.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
